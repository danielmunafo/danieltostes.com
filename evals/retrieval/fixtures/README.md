# Retrieval Fixtures

## corpus-snapshot.json

A pinned version of the production embedding corpus. Generated by running:

```
node services/recruiter-assistant-api/scripts/build-llamaindex-index.mjs
```

Then copying the resulting index file here and committing it. Update this snapshot whenever portfolio content changes and re-verify that all retrieval cases still pass.

The snapshot pins the exact chunk IDs and embedding vectors used when the retrieval cases were authored, so tests remain reproducible regardless of future corpus changes.
